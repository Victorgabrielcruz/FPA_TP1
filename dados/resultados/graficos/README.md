# Organização dos Gráficos

Os gráficos foram separados por tipo de experimento para facilitar navegação:

- `kruskal/`: gráficos do experimento principal aplicado ao algoritmo de Kruskal.
- `micro/`: gráficos do experimento controlado que isola o comportamento do DSU.

Cada subpasta contém um `README.md` com descrição de cada figura e sugestão de ordem de leitura.
